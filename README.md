# Моделирование задач по физике (МФТИ)

Репозиторий с численным моделированием задач по физике, решаемых в рамках учёбы в МФТИ.
Задачи решаются численно на Python, результаты проверяются по аналитическим решениям там, где они существуют.

## Задача: полёт тела, брошенного под углом к горизонту

Тело массой `m` бросают с высоты `h0` со скоростью `v0` под углом `α` к горизонту.
Сравниваются три модели сопротивления воздуха:

| Модель | Сила сопротивления | Уравнение движения |
|---|---|---|
| Без сопротивления | — | `m·dv/dt = m·g` |
| Вязкое (линейное) | `F = −k·v` | `m·dv/dt = m·g − k·v` |
| Лобовое (квадратичное) | `F = −k·|v|·v` | `m·dv/dt = m·g − k·|v|·v` |

### Что считается

- траектории `y(x)` для всех трёх моделей;
- дальность полёта `L`, максимальная высота `H`, время подъёма `t_top`, полное время полёта `T`, скорость в момент падения;
- зависимость модуля скорости от времени и выход на предельную скорость (`mg/k` для вязкого и `√(mg/k)` для лобового сопротивления);
- оптимальный угол броска для каждой модели (зависимость `L(α)`);
- траектории при квадратичном сопротивлении для разных углов;
- предельный переход `k → 0`: при уменьшении сопротивления дальность стремится к теоретической.

### Проверка точности

Для случая без сопротивления и для вязкого сопротивления известны аналитические решения:

- без сопротивления: `x = v0·cos α·t`, `y = h0 + v0·sin α·t − g·t²/2`;
- вязкое сопротивление (`τ = m/k`):
  `x = v0·cos α·τ·(1 − e^(−t/τ))`,
  `y = h0 + v0·sin α·τ·(1 − e^(−t/τ)) − g·τ²·(t/τ − 1 + e^(−t/τ))`.

Программа строит график ошибки `|r_числ − r_теор|` от времени, чтобы оценить точность численного интегрирования.

### Численный метод

Система ОДУ интегрируется через `scipy.integrate.solve_ivp` (метод RK23, `rtol = atol = 1e-9`).
Момент падения (`y = 0`) и верхняя точка траектории (`v_y = 0`) находятся через механизм событий (`events`) решателя.

## Структура проекта

```
├── physics.py        # модели сил, интегрирование, аналитические решения
├── main.py           # параметры задачи, таблица результатов, графики
└── requirements.txt  # зависимости
```

## Установка и запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

Параметры задачи (`v0`, `alpha`, `h0`, `m`, `k_lin`, `k_quad`) задаются в начале файла `main.py`.

После запуска в консоль выводится таблица с результатами для каждой модели и сравнение с теорией, затем открывается окно с шестью графиками.
