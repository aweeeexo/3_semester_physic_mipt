# Моделирование задач по физике (МФТИ)

Репозиторий с численным моделированием задач по физике, решаемых в рамках учёбы в МФТИ.
Задачи решаются численно на Python, результаты проверяются по аналитическим решениям там, где они существуют.

## Задача M11: охлаждение радиатора

Условие — в файле `M11.bmp`: методом случайных блужданий порций энергии рассчитать охлаждение процессора
пассивным радиатором (без вентилятора) и проверить метод на геометрии с аналитическим решением.

### Модель

Поперечный разрез радиатора разбит на клетки `h × h` (длина вдоль рёбер `D`). Тепло — целые порции энергии `ε`.
За шаг `dt` каждая порция с вероятностью 1/2 стоит, с вероятностью 1/2 прыгает к одному из 4 соседей.
В металл — переходит, в воздух — улетает с вероятностью `s` (иначе отскакивает), в плату — отскакивает.
Процессор добавляет `P·dt/ε` порций за шаг.

| Величина | Формула | Смысл |
|---|---|---|
| шаг времени | `dt = h²/(8a)`, `a = λ/(cρ)` | блуждание даёт закон теплопроводности Фурье |
| вероятность ухода | `s = αh/λ` | с поверхности уходит `α·S·(T − T₀)` |
| порция | `ε = cρh²D/q` | `q` порций = 1 К в клетке, `T = T₀ + n/q` |

### Проверка метода

| Проверка | Точный ответ | Что проверяет |
|---|---|---|
| пятно тепла в изолированном стержне | `σ² = 2at`, профиль — гауссиана | теплопроводность по металлу (`dt`) |
| остывание тонкой пластины | `ΔT = ΔT₀·e^(−t/τ)`, `τ = C/(αS)` | теплоотдача в воздух (`s`) |
| баланс энергии | пришло − ушло = запасено | сохраняется точно (целые порции) |

## Структура проекта

```
├── physics.py        # материалы, формулы связи, геометрии, случайное блуждание, точные ответы
├── main.py           # локальный сайт (http.server) + консольная проверка --check
├── web/index.html    # интерактивная страница
├── IDEA.md / SOLUTION.md / CODE.md
├── M11.bmp           # условие задачи
└── requirements.txt
```

## Установка и запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
python main.py            # сайт на http://127.0.0.1:8011, откроется сам
python main.py --check    # проверка метода в консоли
```

Для сайта нужен только `numpy`: сервер написан на стандартной библиотеке.

На сайте:
- мышкой по полю: паяльник (греет), лёд (охлаждает), металл / ластик (меняют форму радиатора на ходу);
- «Среда» (мощность, `α`, температура воздуха) меняется на ходу; «Радиатор» и «Модель» — со сбросом;
- вкладки «Проверка 1/2» показывают сравнение модели с точными формулами.
