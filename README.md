# Моделирование задач по физике (МФТИ)

Репозиторий с численным моделированием задач по физике, решаемых в рамках учёбы в МФТИ.
Задачи решаются численно на Python, результаты проверяются по аналитическим решениям там, где они существуют.

## Задача M3: полёт на Марс

Условие — в файле `M3.bmp`. Корабль (материальная точка) проходит три этапа:

| Этап | Что происходит | Уравнение движения |
|---|---|---|
| 1. Взлёт с Земли | вертикальный разгон с постоянной перегрузкой `n_up`, затем полёт по инерции до границы сферы действия Земли | `dv/dt = n·g₀ − GM_З/r²`, `dm/dt = −m·n·g₀/u` |
| 2. Перелёт | движение по инерции в поле Солнца от орбиты Земли до орбиты Марса | `d²r/dt² = −μ·r/r³` |
| 3. Посадка на Марс | свободное падение от границы сферы действия Марса, затем торможение с перегрузкой `n_down` до нулевой скорости у поверхности | `dv/dt = n·g₀ − GM_М/r²` |

### Что считается

- скорость, которую надо набрать для перелёта (гомановский эллипс при `θ = 0` или минимальная скорость для любого угла вылета `θ`);
- высота и время выключения двигателя, гравитационные потери, расход топлива (формула Циолковского);
- время перелёта, скорость относительно Марса, фазовый угол «где должен быть Марс при старте»;
- высота включения тормозного двигателя, остаточная скорость при посадке;
- перегрузки, которые чувствует экипаж, и их сравнение с допустимым пределом;
- зависимость затрат от перегрузки и от угла вылета;
- полная масса корабля на старте.

### Проверка точности

Почти всё сверяется с аналитикой: радиус выключения и включения двигателя (из интеграла энергии),
параметры гомановского перелёта, сохранение энергии и момента импульса на перелёте.
Ошибки держатся на уровне `10⁻¹⁰`.

### Численный метод

`scipy.integrate.solve_ivp`, метод `DOP853`, `rtol = 1e-10`. Переключения фаз (выключение и включение двигателя,
граница сферы действия, афелий, касание поверхности) находятся через события (`events`) решателя.

## Структура проекта

```
├── physics.py        # константы, уравнения этапов, интегрирование, аналитика
├── main.py           # параметры задачи, проверки, таблица результатов, графики
├── SOLUTION.md       # решение на бумаге + разбор графиков
├── FUNCTIONS.md      # справочник по physics.py
├── M3.bmp            # условие задачи
└── requirements.txt  # зависимости
```

## Установка и запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

Параметры задачи (`n_up`, `n_down`, `u`, `theta`, `m_dry`) задаются в начале файла `main.py`.

После запуска в консоль выводится таблица с результатами по этапам и сравнение с теорией, затем открывается окно с девятью графиками.
